# מילים באנגלית

משחק לימוד מילים באנגלית לילדים בגילאי 10.

כל מילה מוצגת עם תמונה, תרגום והשמעה. אחר כך משלימים אותיות חסרות (3 אפשרויות), ובכל שלב חסרות עוד אותיות, עד הכתבה של המילה כולה.
ההתקדמות, הנקודות והתגים נשמרים בדפדפן של כל ילד.

לשחק: לפתוח את `index.html` בדפדפן, או דרך GitHub Pages של הריפו.

להוספת רשימת מילים: לערוך את `WORD_LISTS` בתחילת הסקריפט ב-`index.html`.
